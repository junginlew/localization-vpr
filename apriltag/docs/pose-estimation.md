# 포즈 추정

카메라 내부 파라미터와 태그 크기가 있으면 AprilTag는 각 태그의 6DoF 포즈를 나타내는 3×3 회전 행렬 `R`과 3차원 이동
벡터 `t`를 복원할 수 있다.

## 값 의미

- `t`는 카메라 프레임에서 태그 원점의 위치이며, 미터 단위이다.
  (`tag_size`와 같은 단위).
- `R`은 카메라 프레임에서의 태그 축 방향이다.

카메라 광학 프레임 규약: +x 오른쪽, +y 아래, +z 전방(렌즈 바깥).

따라서 `t[2]`는 대략 카메라에서 태그까지의 거리이다.

```python
d.pose.t            # [tx, ty, tz] 미터
d.pose.R            # 3x3 회전, 행 우선(row-major)
d.pose.object_error # 재투영 오차 (낮을수록 정확)
```

```cpp
d.pose->t;             // std::array<double,3>
d.pose->R;             // std::array<std::array<double,3>,3>
d.pose->object_error;
```

## 모호성 문제

거의 정면에서 본 평면 태그는 거의 같은 이미지로 투영되는 두 개의 포즈를 가질 수 있다. 이는 버그가 아니라 평면 PnP의 본질적 성질이다.

- 태그가 가만히 있는데도 추정된 방향이 프레임 사이에서 뒤집힘.
- 태그가 카메라를 정면으로 마주할 때 포즈가 떨림.

### 완화책

- 더 큰 태그 사용 / 더 가까이 접근해 원근 단축을 강하게 한다.
- 가능하면 태그를 정면에서 살짝 기울인다.
- 시간적 필터링 적용.
- `object_error` 관찰.

### 다중 태그

강건한 위치 추정을 위해서는, 알려진 상대 포즈로 여러 태그를 강체로 장착하는 것이 좋다
(예: 정육면체의 각 면, 또는 인쇄된 격자).

전부 검출한 뒤 모든 코너를 함께
사용해 단일 포즈를 추정한다.
